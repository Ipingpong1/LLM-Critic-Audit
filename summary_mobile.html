Do LLM critics use what you tell them?

Four open models review 200 ProcessBench math solutions (half flawed) and say “error” or “correct”. One line in the system prompt changes per condition. Signal-detection theory separates skill from threshold.

In one line: the critics barely use a stated base rate, largely ignore stated costs, and don’t improve when told to use either, yet one line of tone (“be harsh”, “be lenient”) moves their threshold as far or further than the whole 10% → 90% base-rate change. No framing changes their skill.

Terms

d′ skill at telling flawed from correct. c threshold: positive is lenient, negative is flag-happy. ρ prior use: how far c moves from a stated 10% to 90% error rate, divided by how far an ideal observer would move. 0 ignores the rate, 1 is ideal.

  • Within qwen, smaller models use the prior more (0.31 → 0.14 → 0.08) while skill rises (d′ 1.79 → 2.24 → 2.57). 4b is reliably above both larger models.
  • The prompt moves the threshold, not the skill: AUC is flat across conditions for every model (0.90–0.96).
  • Default strictness differs a lot: with no instruction the 4b flags 26% of correct solutions, the 27b only 4%.
  • The internal logprob score shifts 15–33% of the Bayesian amount (ln 81), a bit more than the verdicts.

  • Harsh-to-lenient spans 1.03 / 0.64 / 0.29 (4b / 9b / gemma), larger than each model’s full base-rate shift.
  • No framing changes skill (AUC within 0.01). Extra flags are mostly false alarms: 4b under “harsh” gains 9 hits and 23 false alarms. Relevant to adversarial critics told an error exists.
  • Cost asymmetry is ignored in words too. No model gets more lenient when told false alarms are costly, only when told to be lenient.
  • Even the 27b, which ignores rates and payoffs, follows “be lenient” as far as its whole base-rate effect.

Saying vs. doing

Asked before any solution which way to lean, every model says “error” by default. Under a 10% base rate the 27b correctly says “correct” in both option orders, yet barely shifts its verdicts. Only 2 of 8 replies name the right costlier mistake when false alarms cost 9 points.

Caveats

Four open models (three sizes from one family), one dataset, temperature 0, one sample, stated not true base rate, possible contamination, one phrasing per framing. Thinking was off throughout.
